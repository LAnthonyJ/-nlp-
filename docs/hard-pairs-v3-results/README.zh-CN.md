# 标准 DPO 在两套评测上小幅超过 SFT

本轮从冻结的 SFT step-64 出发，每条候选路径各训练一次标准 DPO，种子为 42。筛出的 511 对训练样本同时满足模型答错、训练编码下模型给错答的概率更高、两侧 token 数之比不超过 1.5。两种学习率都只按开发集选模。最终 DPO 采用学习率 0.00002 的第 8 步，监督对照采用学习率 0.00008 的第 32 步，两组获得相同的样本、候选学习率和最大更新预算。[复现说明](../hard-pairs-v3.md)

| 四项等权平均正确率 | 冻结 SFT | 标准 DPO | 仅学习正确答案 | DPO 相对 SFT 的配对 95% 区间 |
|---|---:|---:|---:|---:|
| 新保留集，768 题 | 44.66% | 45.57% | 52.73% | +0.13 至 +1.82 个百分点 |
| 既有公开评测，13,680 题 | 43.49% | 43.64% | 未测 | −0.35 至 +0.66 个百分点 |

新保留集上，DPO 在 PIQA 净增 2 题，在 SVAMP 净增 5 题。HellaSwag 和自建指令题净变化均为零。四项均分增加 0.91 个百分点，校正单侧下界为零，未通过预设验收。仅学正确答案的对照比 DPO 高 7.16 个百分点，配对 95% 区间为 +5.08 至 +9.24。

保留集的 192 道 SVAMP 题中，评分器无法提取唯一有效数值的回答分别有 109 个（SFT）、102 个（DPO）和 29 个（监督对照）。这是监督对照领先的一条可检验线索；格式通过本身不能保证算术正确。

锁定权重后在同一台 RTX 3060 上完整运行公开基准。DPO 相对 SFT 的正确率变化为 PIQA −0.27、HellaSwag +0.06、IFEval strict +0.74、GSM8K +0.08 个百分点。等权平均增益为 +0.15，区间跨零。新保留集和历史公开数据的任务分布不同。结果限于该种子、所选权重和测试协议。[逐项错转对、对转错、区间与权重哈希](metrics.json)
